# How APIs Work

An interactive, single-page walkthrough of how web APIs work: requests, headers, payloads, responses, status codes and JWT tokens. It ends with examples of attack payloads carried in request headers and bodies.

Live calls go to free public test APIs:

- [DummyJSON](https://dummyjson.com/docs): products, users, login with JWT
- [httpbin](https://httpbin.org/): echoes back exactly what the server received
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/guide/): simple fake REST data

## Use it

Open `index.html` in a browser. No server or build step is needed.

Keyboard: `←` / `→` change step, `Ctrl+Enter` sends the request.
